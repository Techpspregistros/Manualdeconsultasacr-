# ARC+ Enterprise v5.1 — Inicio simplificado

Esta versión elimina la necesidad de ejecutar FastAPI y Streamlit en dos consolas distintas.
La aplicación funciona como un solo proceso local.

## Instalación

1. Descomprima el paquete en una carpeta nueva.
2. Ejecute `instalar_v5_1.bat` una sola vez.
3. Ejecute `INICIAR_ARC_PLUS.bat` cada vez que desee utilizar el sistema.
4. El navegador se abrirá automáticamente.

El iniciador busca un puerto libre entre 8501 y 8599. Por eso puede convivir con versiones anteriores sin mostrar errores por puerto ocupado.

## Primer acceso

- Usuario: `admin`
- Contraseña: `Cambiar123!`

Cambie la contraseña inmediatamente desde el módulo **Usuarios**.

## Funciones incluidas

- Inicio de sesión y roles.
- Consulta de múltiples manuales.
- Respuestas con documento y página exacta.
- Visualización de páginas PDF.
- Historial por usuario y agencia.
- Retroalimentación y aprendizaje supervisado.
- Diccionario de sinónimos.
- Preguntas frecuentes oficiales.
- Biblioteca documental.
- Dashboard de consultas.
- Auditoría.

## Importante

Mantenga abierta la ventana negra mientras utiliza el sistema. Para detenerlo, cierre esa ventana o presione `Ctrl+C`.

Esta edición está optimizada para uso local. La publicación web multiusuario debe usar PostgreSQL, HTTPS, copias de seguridad y autenticación corporativa.
